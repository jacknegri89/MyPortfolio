JobScraper

Riunisce le offerte di lavoro da 13 fonti tra Lombardia e Canton Ticino in una dashboard locale. Filtra per zona, distanza, settore e contratto, elimina i duplicati e distingue annunci nuovi, già visti o da verificare. Mostra la provenienza delle retribuzioni e le stime nette per Italia e Svizzera; il punteggio con OpenAI è facoltativo.

  • Playwright

  • OpenAI API
  • Dashboard offline

LogLens

Analizza log e stack trace di diversi formati, raggruppa gli eventi in incidenti e collega ogni possibile causa alle righe che la supportano. Include oltre 50 regole senza AI, analisi opzionale con OpenAI o Ollama, storico, report condivisibili e GitHub Issue pronte da copiare. Il Workbench offre ricerca avanzata, raggruppamento, tracce e strumenti per mascherare i dati sensibili. La demo live usa la modalità ibrida.

  • React

  • Prisma
  • PostgreSQL
  • Vitest
  • Playwright

Le conclusioni distinguono cause confermate, probabili e ipotesi. Benchmark su 15 scenari e test automatici con Vitest e Playwright in GitHub Actions.

Secure Notes

App blocco note con crittografia locale AES: ogni nota viene cifrata prima di essere salvata ed è accessibile solo con una password personale, mai memorizzata in chiaro. Completamente offline.
